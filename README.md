Інтерактивний тренажер «Аналіз історичних джерел: Історія України, 10 клас»
Інтерактивний вебдодаток для учнів 10 класу, створений для відпрацювання навичок аналізу історичних документів (підготовка до НМТ/ЗНО). Застосунок динамічно завантажує базу запитань із Google Таблиць, підсвічує ключові слова-маркери в поясненнях, зберігає прогрес користувача та автоматично підраховує відсоток успішності.
